Aprendizado contínuo

A construção deste próprio site é o veículo atual de aprendizado de desenvolvimento web. Cada projeto no GitHub é também um corpo de estudo.

Sobre este site

Este site é construído camada por camada, como parte do projeto learn-web. A camada atual cobre estrutura semântica em HTML e estilização em CSS. Em camadas seguintes serão adicionadas interatividade em JavaScript, conteúdo dinâmico em PHP e persistência em banco de dados.

O código-fonte e a documentação técnica estão abertos no repositório.
