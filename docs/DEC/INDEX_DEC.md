## Como criar uma nova DEC

1. Numerar sequencialmente após a última DEC existente (próxima livre: **DEC-001**).
2. Nome do arquivo: `DEC_NNN_descricao_curta.md`.
3. Frontmatter mínimo: `documento`, `titulo`, `versao`, `status: proposto`, `data`, `autor`.
4. Conteúdo obrigatório (SPEC-001 §7.3): Contexto, Decisão, **Alternativas consideradas** (≥ 2, com motivo de descarte), **Consequências** (com seção dedicada a consequências negativas), Critérios de reavaliação.
5. Após aprovação ativa do autor, atualizar este índice.
